# Prasanth Ayitapu — Technical Portfolio

A responsive, dark portfolio for technical job applications, built with plain HTML and CSS. No build step or backend is required.

## Preview
Open `index.html` in a browser.

## Before publishing
1. Add your real résumé PDF as `assets/Prasanth_Ayitapu_Resume.pdf`.
2. Replace the `PA` placeholder with a professional photo (instructions below).
3. Replace the LinkedIn and GitHub placeholder URLs with your actual profiles.
4. Add verified repository/demo links to projects where possible. Do not claim a public repository or live demo unless it exists.
5. Review the descriptions to ensure each bullet accurately reflects your contribution.

### Add your photo
Put `profile.jpg` in `assets/`, replace the `<div class="portrait">...</div>` element with:
`<img class="portrait-img" src="assets/profile.jpg" alt="Prasanth Ayitapu">`
Then add this CSS:
`.portrait-img { width:126px; aspect-ratio:1; object-fit:cover; border:1px solid #454b55; border-radius:10px; }`

## Free hosting with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `README.md`, and the `assets` folder.
3. Go to repository **Settings → Pages** and enable deployment from the `main` branch, root folder.
4. Visit `https://YOUR-USERNAME.github.io/`.

## Positioning
The site emphasizes verifiable engineering experience: Python applications, Flask deployment, Linux/Gunicorn, data pipelines, document extraction, applied ML, and forecasting. It intentionally does not label you a full-stack engineer.
